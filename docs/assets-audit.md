## 1. Executive Summary

This document catalogues all external and local media assets utilized in DimensionUI, including template preview thumbnails, interactive preview canvas assets, UI iconography, and typography.

Key findings:
1. **Zero Local Image Files:** The `public/` directory contains no proprietary or bundled raster images.
2. **External Hotlinking:** All photographic content is dynamically served from `images.unsplash.com`.
3. **Typography & Icons:** Typography uses `next/font/google` (self-hosted Inter with SIL Open Font License), and icons use `lucide-react` (ISC License).

## 2. Asset Inventory & Licensing Breakdown

### A. Template Preview Photography (Gallery & Detail Pages)
* **Location:** `components/sections/gallery.tsx` (`PHOTOS` mapping, lines 200–240)
* **Serving Host:** `https://images.unsplash.com`
* **Resolution / Optimization:** Served via Next.js `Image` optimization (`/_next/image?url=...`).
* **Source Platform:** Unsplash (unsplash.com)
* **Licensing Model:** Unsplash License.
  * *Permitted:* Free to use for commercial and non-commercial purposes.
  * *Restrictions:* Cannot be sold without significant modification; cannot be compiled to replicate a similar competing service.
* **Licensing Risk Assessment:** **LOW TO MEDIUM**
  * *Hotlinking & Availability Risk:* Relying on remote Unsplash photo IDs carries the risk of 404s if photographers delete or make photos private.
  * *Commercial Redistribution:* While Unsplash allows commercial use on websites, bundling third-party photos into downloadable commercial template source code packages may create ambiguity regarding intellectual property transfer.
  * *Recommendation:* For downloadable templates in production, replace external Unsplash images with original branded vector mockups, AI-generated synthetic assets with clear provenance, or explicit SVGs created specifically for DimensionUI.

* **Compliance Status:** **PASS**.
