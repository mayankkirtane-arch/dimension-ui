# 2026-09-16

## DimensionUI — SaaS landing page (foundation + hero)

Built the foundational layout, sticky glass navbar, and interactive 3D hero for
"DimensionUI" (a 3D/interactive web-component vault product).

**Stack:** Next.js 15.5.25 (App Router), React 19, Tailwind CSS v4.3.3
(`@tailwindcss/postcss`), Framer Motion, Lucide React, TypeScript strict.

### Key files
- `app/globals.css` — design tokens via `@theme`, custom `@utility` layer
  (`glass`, `glass-solid`, `text-gradient-neon`, `text-gradient-brand`,
  `glow-purple`, `glow-cyan`, `bg-dot-grid`, `mask-radial-fade`,
  `shimmer-sweep`), keyframes, base layer.
- `app/layout.tsx` — Inter via `next/font`, metadata, fixed `AmbientBackdrop`.
- `lib/site.ts` — all copy + anchor ids in one place (nav, hero, pills,
  placeholder sections).
- `lib/hooks.ts` — `useScrollProgress`, `useScrolled`, `scrollToHash` (88px
  navbar offset), `useSmoothScroll`.
- `lib/particle-field.ts` — framework-agnostic 3D particle sim: unit-cube space,
  seeded mulberry32 RNG, perspective projection, magnetic attraction, O(n²)
  link collection with an X/Y early-reject, reuse of scratch buffers.
- `components/particle-canvas.tsx` — canvas host: DPR capped at 2, ResizeObserver,
  IntersectionObserver + visibilitychange to pause offscreen, dt clamp,
  reduced-motion slowdown, additive `lighter` compositing, radial-gradient
  bloom only on near particles.
- `components/navbar.tsx` — sticky glass nav, scroll progress hairline,
  IntersectionObserver active-section pill (`layoutId`), mobile sheet with
  Escape/outside-click close + body scroll lock.
- `components/hero.tsx`, `components/brand-mark.tsx`,
  `components/section-anchors.tsx`, `components/ambient-backdrop.tsx`.

### Two real bugs found and fixed (both via headless-Chrome CDP probing)
1. **CTA class conflict.** `CtaButton` hard-coded `inline-flex` in its base
   classes while callers passed `hidden sm:inline-flex`. Both ended up in the
   class list and `inline-flex` wins Tailwind's output order, so the navbar CTA
   never hid on mobile — it squeezed the header until the hamburger was pushed
   off-screen. Fix: `CtaButton` no longer sets `display`; callers supply it
   (`hidden sm:inline-flex` in the header, `fullWidth` → `flex w-full` in the
   sheet).
2. **Invisible mobile sheet.** The `glass` utility used only a very low-alpha
   white gradient. `backdrop-filter` does not darken, so over the bright hero
   the menu links were unreadable. Fix: give `glass` an opaque-ish obsidian base
   (`rgba(14,14,26,0.82)`) and add a denser `glass-solid`
   (`rgba(10,10,18,0.94)`) for the mobile sheet.

### Verification tooling (reusable)
`scripts/verify-responsive.js` and `scripts/verify-menu.js` drive headless
Chrome over the DevTools Protocol (via `ws`, installed with `--no-save`):
multi-viewport screenshots, computed-style assertions, real `Input.dispatchMouseEvent`
taps, Escape handling, body-scroll-lock checks, anchor-offset checks, and
console/exception capture. `scripts/inspect-element.js` dumps every CSS rule
matching a selector at a given viewport.

Final state: `tsc --noEmit` clean, `next build` clean (static prerender,
154 kB First Load JS), responsive + menu suites ALL PASS, zero console errors.

### Environment gotchas (cost real time)
- **`/tmp` is not writable** in this shell; write probe output into the project
  dir instead.
- **`grep -c` is useless on minified CSS** (one giant line → always returns 1).
  Use `grep -o ... | wc -l`.
- **A dead `next start` process leaves a proxy answering on the port with
  HTTP 502** and an HTML error body. That silently produced blank screenshots
  and "element not found" probes for several rounds. Always assert
  `curl` returns 200 *and* grep for real markup before trusting a probe.
- `--virtual-time-budget` screenshots are flaky with Framer Motion entrance
  animations; CDP `Page.captureScreenshot` after a real sleep is reliable.
- Inline `node -e` with Windows paths gets mangled by bash escaping — write a
  script file instead.
